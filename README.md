# StudyFlow v9 完全版

## 修正点
- メンテナンス画面の管理者ボタンを押しても進まない問題を修正しました。原因は管理者モーダルよりメンテナンス画面の重なり順が上だったことです。
- `maintenance.json` を全利用者共通の状態として15秒ごとに確認します。
- `enabled: true` で全利用者にメンテナンス画面、`false` で終了します。
- 学習履歴は各利用者のlocalStorageに残ります。

## 全体メンテナンスの変更
管理者ボタンから認証後「GitHubで設定を切り替える」を押し、`maintenance.json` の enabled を変更してCommitします。

GitHub Pagesは静的サイトなので、ブラウザへGitHub書き込み用トークンを保存せずに、画面内スイッチだけでリポジトリを書き換えることはできません。この版は安全のためGitHub編集画面へ移動します。

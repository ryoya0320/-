# Memoria

カップル・大切な人同士で使える、iPhone / GitHub Pages向けの軽量な思い出アルバムWebアプリです。

## 配置
このフォルダの `index.html`, `style.css`, `app.js`, `config.js`, `manifest.webmanifest` をGitHub Pages公開対象の同名ファイルへ丸ごと置き換えてください。既存の `icon.png` と `icon.svg` はそのまま残します。

## 現在の保存先
- 写真: IndexedDB。保存前に最大1600px程度のJPEGへ1枚ずつ圧縮します。
- カレンダー、やりたいこと、プロフィール、ローカル友だち情報、DMデモ: localStorage。
- 認証はありません。起動直後にホームを表示します。

## Supabase
`config.js` は空設定で開始します。

```js
window.MEMORIA_CONFIG = {
  supabaseUrl: "",
  supabaseAnonKey: ""
};
```

現基準版はSupabaseへ通信しません。将来は「友だちID単位」のDM/友だちレイヤーと「共有ルーム単位」のアルバム/予定/Wish/記念日レイヤーを別テーブル、別サービスとして接続してください。認証もその段階で追加する想定です。

## GitHub Pages / iPhone
相対パスを使っているので、ユーザー/Organization PagesだけでなくプロジェクトPagesのサブパスでも配置しやすい構成です。Safariでは共有メニューから「ホーム画面に追加」してください。

## 主な機能
- 5タブの固定下部ナビ
- ホーム: 表示名、経過日数、ショートカット、トーク、最新3日/最大9枚の思い出
- 写真追加: カメラ1枚、写真ライブラリ複数枚、一括メタデータ、逐次圧縮・保存、個別失敗継続
- アルバム: 一覧、詳細、削除
- 月間カレンダー: 前後月、予定CRUD、25種のマーク、記念日自動生成
- やりたいこと: 追加、編集、削除、完了
- プロフィール: 名前、ひとこと、画像、背景、記念日、テーマ/アプリ/DM背景色、DM背景画像、DM ID
- 友だち/DM UI: ローカルデモ。オンライン申請、同期、既読同期はSupabase接続後に実装するため境界を分けています。

## 注意
写真は端末ブラウザ内に保存されます。Safariのサイトデータを削除すると消える可能性があるため、重要写真の唯一の保管場所にはしないでください。
